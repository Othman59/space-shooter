🚀 Space Shooter – Godot
###
🎮 Description

Space Shooter est un jeu d’arcade en 2D développé avec le moteur Godot.
Le joueur contrôle un vaisseau spatial et doit survivre face à des vagues de méteorite tout en évitant les projectiles et en marquant un maximum de points.

Le gameplay s’inspire des classiques du genre : déplacements rapides, et difficulté progressive.

🛠️ Technologies utilisées

Moteur de jeu : Godot Engine

Langage : GDScript

Graphismes : 2D

Plateforme cible : PC (Windows / Linux / macOS)

🎯 Fonctionnalités

Déplacement du vaisseau du joueur

Tir de projectiles

Ennemis avec patterns simples

Système de score
